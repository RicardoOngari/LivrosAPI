# 📚 Busca de Livros - Consumo de API com React.js

Projeto desenvolvido para a Sprint de **Consumo de API** com React.js, que busca livros na API pública da **Open Library** e exibe título, autor, ano de publicação e capa. Além disso, conta com o botão interativo **"Tente a Sorte"**, que exibe um livro aleatório.

---




## 🛠️ Tecnologias Utilizadas

- React.js (JavaScript)
- Axios (requisições HTTP)
- CSS (estilização separada)
- HTML semântico
- Open Library API

---

## 🎨 Funcionalidades

- Campo de busca para livros
- Botão "Buscar" que retorna até 10 resultados
- Botão "🎲 Tente a Sorte" que retorna um livro aleatório
- Exibição de 4 propriedades:
  - **Título**
  - **Autor**
  - **Ano de publicação**
  - **Imagem da capa**
- Layout responsivo e estilizado
- Código fonte organizado e comentado
